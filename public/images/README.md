# Photography slots

Drop final images here (JPG/WebP, sRGB) and pass `src="/images/<file>"` to the matching `<Photo>`.
`next/image` handles resizing and AVIF/WebP delivery. Prefer genuine CYORA / Sri Lankan cinnamon photography.
If an image is AI-generated, add the `illustrative` prop so it is labelled and never read as documentary.

**Current state:** every file below is an AI-generated stand-in (Higgsfield — Seedream 5.0 Flash; `hero-plantation.jpg`
via Z Image) and is rendered with `illustrative`, so it carries an "Illustrative image" caption. None of them shows a
CYORA farm, worker, facility or real product pack, and the packaging shots are deliberately unbranded with no claims.
To swap in genuine photography, overwrite the file (same name, similar aspect) and remove `illustrative` from that
`<Photo>` (or `illustrative: true` from the hero/gallery object) — but only for real, documentary photos.
